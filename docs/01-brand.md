# Baroj Brand

> AI-first brand specification for Cursor.

## Purpose
This document defines the Baroj brand identity, personality, tone, and non-negotiable principles. AI assistants must follow these rules when generating UI, UX, code comments, marketing copy, or product features.

## Core Principles
- Trust before growth.
- Clarity before complexity.
- Calm before excitement.
- Honest communication.
- Long-term user value.

## Brand Personality
Professional, calm, modern, reliable, human-centered.

## Brand Voice
Clear, concise, respectful, confident, never exaggerated.

## AI Rules
- Never use dark patterns.
- Never exaggerate product capabilities.
- Prefer simple interfaces.
- Reduce user anxiety.
- Keep consistency across all features.

## Non Goals
- Clickbait
- Manipulative UX
- Visual clutter
- False urgency
