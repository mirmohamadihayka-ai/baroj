# Frontend

> AI-first frontend architecture rules for Baroj.

## Purpose
Define standards for frontend implementation.

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS

## Rules
- Component-first architecture.
- Feature-based folders.
- Reusable UI.
- Accessibility by default.
- Mobile-first.
- Performance-first.

## AI Instructions
Always follow Design System and UX Rules before generating UI.
