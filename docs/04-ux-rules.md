# UX Rules

## Purpose
Define UX rules for Baroj that every AI agent and developer must follow.

## Core Principles
- Clarity over complexity.
- Trust before conversion.
- Consistency across all screens.
- Minimize cognitive load.
- One primary action per screen.

## Navigation Rules
- Predictable navigation.
- Keep important actions visible.
- Never hide critical information.

## Forms
- Ask only for required information.
- Validate inline.
- Explain errors clearly.

## Feedback
- Every action must provide feedback.
- Loading states must be visible.
- Success and error states must be explicit.

## Accessibility
- Keyboard friendly.
- High contrast.
- Clear focus states.

## AI Rules
- Prefer simple flows.
- Avoid dark patterns.
- Reduce user anxiety.
- Design for confidence.
- Follow docs/01-brand.md and docs/02-design-system.md before creating UI.
