# Baroj Design System

> Version: 0.1

## Purpose
This document defines the visual and interaction rules for Baroj. Every UI generated by Cursor must follow these rules.

## Principles
- Clarity over decoration.
- Consistency over creativity.
- Trust before conversion.
- Simplicity first.
- Accessibility by default.

## Color Philosophy
Use a calm, modern and trustworthy palette. Avoid saturated colors unless used for status.

## Typography
Readable, spacious, consistent hierarchy.

## Spacing
Use an 8px spacing system.

## Components
Components must be reusable, composable and consistent.

## Motion
Animations should be subtle, purposeful and under 300ms.

## Accessibility
Meet WCAG AA where possible.

## AI Rules
- Never invent new component styles.
- Reuse existing patterns.
- Prefer consistency over novelty.
- Reduce cognitive load.
- Always design mobile-first.
