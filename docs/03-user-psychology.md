# 03 - User Psychology

## Purpose
Define the psychological principles that guide every UX, UI and AI decision in Baroj.

## Core Principles
- Reduce anxiety.
- Build trust before conversion.
- Keep cognitive load low.
- Make every decision reversible when possible.
- Show transparency.

## User Motivations
- Find the right property.
- Save time.
- Avoid scams.
- Make confident decisions.

## User Fears
- Fake listings.
- Hidden costs.
- Wasting time.
- Poor communication.

## Trust Signals
- Verified information.
- Clear pricing.
- Honest language.
- Fast feedback.

## UX Rules
- Never overwhelm users.
- Keep flows predictable.
- Explain errors clearly.
- Always provide a next step.

## AI Rules
Cursor must prioritize user confidence over visual complexity. Every feature should reduce uncertainty and improve clarity.
