# 27 — MAI-37 Migration Validation + PostgreSQL Integration Gate

## Purpose
Validate the MAI-36 persistence slice without inventing a database environment or claiming checks that have not been executed.

## Findings

### 1. Lockfile is currently stale
`package.json` declares Drizzle ORM, pg, Drizzle Kit, and @types/pg, but the committed `package-lock.json` root package entry still reflects the pre-MAI-36 dependency set.

This blocks a trustworthy `npm ci` validation. The lockfile must be regenerated by npm in a networked development environment and committed with the exact resolved dependency graph.

### 2. PostgreSQL runtime validation is unavailable here
No approved PostgreSQL instance/credentials are available to this execution environment. Therefore the first durable migration and repository integration query have not been executed against PostgreSQL.

### 3. Runtime initialization was hardened
MAI-37 changes database initialization from module-import time to lazy runtime initialization. Missing `DATABASE_URL` therefore fails when the database is actually requested instead of during unrelated module loading/build analysis.

### 4. Free-text semantics remain gated
A non-empty `query` is still rejected rather than silently ignored. No full-text, fuzzy, tokenization, ranking, or search-engine behavior is introduced.

## Required Completion Sequence

1. Run `npm install` on a networked development machine to regenerate `package-lock.json` from the approved `package.json`.
2. Run `npm run typecheck`.
3. Run `npm run build`.
4. Run `npm run db:generate` and review the generated migration.
5. Apply the migration against an approved PostgreSQL development database.
6. Execute an integration test covering propertyType/location/minPrice/maxPrice and empty results.
7. Verify unsupported non-empty `query` is rejected safely.
8. Commit the reviewed migration and updated lockfile.

## Gate

MAI-37 is **not implementation-complete** until the blocked checks above are executed successfully. No claim of successful PostgreSQL integration is made by this document.
